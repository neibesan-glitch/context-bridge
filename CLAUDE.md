# Projet : Base de Connaissances IA Agnostique

Ce fichier fournit aux agents IA (comme Claude Code, Cursor, Windsurf, ou Antigravity) les directives pour comprendre l'état du projet et collaborer sans perte de contexte.

## Directives pour l'Agent IA (Système de Mémoire)

> [!IMPORTANT]
> Avant de commencer toute tâche, vous devez lire le fichier d'aiguillage principal du projet : [docs/INDEX.md](docs/INDEX.md).
> Ce fichier contient les liens vers l'architecture, la carte du code, et les décisions techniques.

### Suivi de l'État
- **Tâches en cours** : Consultez et mettez à jour le fichier `task.md` à la racine (s'il existe) pour savoir où s'est arrêté le précédent agent.
- **Dernières modifications** : Consultez `walkthrough.md` (s'il existe) pour voir l'historique des modifications apportées et les tests validés.
- **Journal d'immunité** : Consultez `docs/memoire/journal_erreurs.md` pour ne pas répéter les erreurs déjà résolues par les agents précédents.
